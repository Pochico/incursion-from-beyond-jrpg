# Fondos de ubicación

Si existe `<id>.png`, `<id>.jpg` o `<id>.webp` (p. ej. `plaza.png`), se usa como fondo
de esa ubicación (escenario y conversación). Si no, se genera un fondo provisional
por código (`src/screens/world/location_backdrop.gd`).

Ids actuales: ver `src/data/location_db.gd`. Resolución recomendada: 1920×1080.
